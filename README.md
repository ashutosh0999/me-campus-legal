# me_campus — legal pages

The privacy policy and terms of use for the **me_campus** student app,
published with GitHub Pages.

- [Privacy Policy](https://ashutosh0999.github.io/me-campus-legal/privacy.html)
- [Terms of Use](https://ashutosh0999.github.io/me-campus-legal/terms.html)
- [Delete your account](https://ashutosh0999.github.io/me-campus-legal/delete-account.html)

This repository is public because Google Play requires a reachable privacy
policy URL. It contains **only** these pages — the app's source code is
private.

Do not edit the HTML here. It is generated from Markdown sources in the main
repository by `scripts/build_legal_site.py`; edits made here are overwritten
on the next publish.
